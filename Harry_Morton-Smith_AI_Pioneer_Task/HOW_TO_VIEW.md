# How to view this

**Just want to see it? Do this:**

1. Extract the whole zip to a folder (right-click → "Extract All" on Windows,
   or double-click on Mac) — don't open files straight out of the zip
   preview, extract the folder properly first.
2. Open `dashboard/dashboard.html` by double-clicking it. It opens in your
   default browser.

That's it — no install, no terminal, no Python needed. The dashboard has all
its data built directly into the file, so it works standalone even if it
gets separated from the rest of the folder.
